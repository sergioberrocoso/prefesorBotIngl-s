# 📚 English Learning Bot for Graphic Arts

Un bot de aprendizaje de inglés diseñado específicamente para profesionales del sector de artes gráficas y litografía, nivel A2-B1.

## 🎯 Características

### 1. **Vocabulario Especializado**
- Terminología específica de impresión y litografía
- 32 términos técnicos organizados en 4 categorías:
  - Términos de impresión (Offset, Lithography, Print run, etc.)
  - Materiales (Paper stock, Ink, Coating, etc.)
  - Procesos (Die cutting, Embossing, Folding, etc.)
  - Términos comerciales (Quote, Purchase order, Invoice, etc.)
- Audio para cada palabra y ejemplo
- Seguimiento de progreso de palabras aprendidas

### 2. **Práctica de Escritura de Emails**
- 4 plantillas de emails profesionales:
  - ✉️ Consulta de precios
  - 📋 Orden de compra
  - 💰 Solicitud de presupuesto
  - 🔄 Seguimiento
- Verificación automática de formato y tono profesional
- Consejos específicos para cada tipo de email
- Función de lectura en voz alta

### 3. **Conversación con Audio**
- 4 escenarios de conversación realistas:
  - 👋 Saludar visitantes
  - 📞 Llamadas telefónicas
  - 💼 Negociación de precios
  - ☕ Conversaciones informales
- Reconocimiento de voz integrado
- Síntesis de voz para las respuestas del bot
- Práctica de conversaciones fluidas

### 4. **Seguimiento de Progreso**
- Contador de palabras aprendidas
- Contador de emails practicados
- Contador de conversaciones completadas
- Almacenamiento local (sin necesidad de cuenta)

## 💡 Consejos de Uso

1. **Para mejor reconocimiento de voz:**
   - Usa auriculares con micrófono
   - Habla claramente y sin apuros
   - Asegúrate de permitir el acceso al micrófono

2. **Para aprender efectivamente:**
   - Dedica 15-20 minutos diarios
   - Repasa el vocabulario regularmente
   - Practica cada tipo de email al menos 3 veces
   - Completa todos los escenarios de conversación

3. **Para usar en móvil:**
   - Usa Chrome para mejor compatibilidad
   - Permite el acceso al micrófono cuando se solicite
   - La interfaz se adapta automáticamente a pantallas pequeñas

## 🔒 Privacidad
